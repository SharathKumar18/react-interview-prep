# Expo and EAS

## Expo Production App Scenario

Design an application using Expo Router, EAS Build, EAS Submit, and EAS Update.

Cover:
- File-based routing.
- Native modules and config plugins.
- Environment-specific configuration.
- Signing credentials and CI/CD.
- Staged releases and rollback.
- Compatibility between JavaScript bundles and native binaries.

Follow-up: What happens if a JavaScript update requires a native module that is absent from the installed binary?
