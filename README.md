# Frontend Engineering Playbook
A practical knowledge base for frontend and mobile engineers preparing for senior-level engineering interviews and building production-grade applications.

## Topics

- **JavaScript & TypeScript:** ES6+, asynchronous programming, closures, typing, and coding problems.
- **React:** Hooks, rendering, component design, state management, and performance.
- **React Native:** Architecture, JSI, Hermes, Expo, navigation, native integrations, and profiling.
- **System Design:** Mobile architecture, caching, offline-first systems, API integration, and scalable UI systems.
- **Testing:** Jest, React Native Testing Library, Maestro, and Appium.
- **AI Engineering:** Agents, MCP, skills, specification-driven development, and AI-assisted testing.
- **Engineering Practices:** CI/CD, application signing, release management, accessibility, and production debugging.
- **Interview Preparation:** Coding exercises, system design scenarios, and behavioral questions.

## Goals

1. Build strong fundamentals through hands-on exercises.
2. Understand architectural trade-offs instead of memorizing answers.
3. Develop reliable, performant, and accessible mobile applications.
4. Use AI tools effectively while maintaining engineering quality.

## How to Use This Repository
Each topic should include:

- Core concepts and explanations
- Practical examples and code
- Common interview questions
- Trade-offs and follow-up questions
- Testing and production considerations
