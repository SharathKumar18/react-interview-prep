# Behavioral Interview Questions

## Interview Answer Frameworks

### Coding

1. Clarify requirements and edge cases.
2. State a simple approach.
3. Implement readable code.
4. Test normal, boundary, and failure cases.
5. Discuss complexity and trade-offs.

### System Design

1. Clarify requirements and scale.
2. Draw components and data flow.
3. Explain state, API, cache, and persistence.
4. Address reliability, performance, security, and accessibility.
5. Discuss trade-offs and failure scenarios.

## Senior React Native / Frontend Preparation Checklist

- [ ] Implement debounced search with cancellation and race-condition handling.
- [ ] Practise virtualized lists and efficient state updates.
- [ ] Explain an e-commerce app architecture in 10 minutes.
- [ ] Explain offline-first synchronization and conflict resolution.
- [ ] Distinguish JavaScript-thread stalls from native UI bottlenecks.
- [ ] Explain startup profiling, memory leaks, and frame drops.
- [ ] Review JSI, Hermes, Fabric, and TurboModules.
- [ ] Review MCP, agents, skills, and specification-driven development.
- [ ] Review accessibility, Expo/EAS, signing, and deployment.
