# AI-Assisted Development

## Engineering Workflow

Use a reviewable sequence:

**Specification → Plan → Implementation → Tests → Review → Validation**

Provide repository conventions and acceptance criteria before implementation. Keep changes scoped, run relevant tests, inspect generated code, and treat test results as evidence to review rather than automatic proof of correctness.

## Measuring Productivity

How would you measure whether AI increases developer productivity by 50%? Do not claim a productivity improvement without explaining how it was measured. Consider cycle time, review effort, escaped defects, test quality, and rework, and compare equivalent work over a defined period.

## Security and Accountability

Protect secrets, customer data, and proprietary code according to the organization's approved tooling and data-handling policies. Review generated code for security issues and architectural violations. Engineers remain accountable for correctness, security, and production readiness.
