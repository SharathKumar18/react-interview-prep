# Agents, MCP, and Skills

## Interview Questions

1. What is the difference between an AI agent, MCP, and a skill?
2. How would you provide a coding agent with a specification before implementation?
3. How would you use an agent to implement a React Native screen from a Figma design?
4. How would you automate test generation, execution, and fixing failures?
5. How do you protect secrets, customer data, and proprietary code when using AI tools?

An agent can use repository tools through MCP, follow a skill containing project conventions, and iterate based on test results. Engineers remain accountable for correctness, security, and production readiness.
